# vault-tool 本地文件加密

- **这是什么：**把选定的文件加密成 `vault.enc`，以后可在本机输入密码查看或取出。
- **我怎么用：**运行 `python vault_tool.py`，在本地菜单选择加密、查看或导出；默认保留原件。
- **怎么知道正常：**加密完成后，在本机用原密码实际打开并核对需要的文件；只看“加密成功”还不够。
- **坏了怎么提醒我：**没有自动提醒，出问题直接跟 AI 说。
- **让 AI 做什么：**让 AI 用 `info`、`doctor` 或 `plan` 检查元数据和操作步骤；密码只在本机输入，不发给 AI。

私人 Key 仓库的密文备份与回读步骤见 [Key 仓库工作流](docs/key-repository-workflow.md)。密码或必要密钥文件遗失后无法找回。
